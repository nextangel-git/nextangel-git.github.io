# Инструкция по работе с админкой сайта УК «Жилкомсервис»

Для сотрудника УК. Ничего устанавливать и настраивать не нужно — только браузер и телефон.

## Вход

1. Откройте адрес админки (сейчас — у администратора сайта; после переезда на хостинг — `https://admin.jks.ooo`).
2. Введите **логин** и **пароль**, которые выдал администратор.
3. Введите символы с картинки («Я не робот»).
4. **Первый вход — настройка двухфакторной защиты:**
   - Установите на телефон приложение **Яндекс Ключ** или **Google Authenticator** (бесплатно, App Store / Google Play).
   - В приложении: «+» → «Сканировать QR-код» → наведите на код на экране.
   - Введите 6 цифр, которые покажет приложение. Готово — это делается один раз.
5. При следующих входах: логин, пароль, капча и 6-значный код из приложения. Код меняется каждые 30 секунд, вводить можно текущий.

**Если потеряли телефон / удалили приложение** — попросите администратора сбросить 2FA (команда `--reset-totp`), при следующем входе настроите заново.

**Если забыли пароль** — администратор задаст новый (команда `--passwd`). Самостоятельно сменить пароль можно в разделе «Сменить пароль» после входа.

## Как устроена админка

Слева — меню разделов с количеством записей. Справа вверху — ваше имя и кнопка «выйти». Кнопка «Открыть сайт» — посмотреть результат на сайте.

**Важно:** после нажатия «Сохранить» изменения появляются на сайте не мгновенно, а через **2–3 минуты** — сайт пересобирается автоматически. Это нормально, ничего дополнительно нажимать не нужно.

## Разделы

### Новости
- «+ Добавить новость» → заголовок, дата (подставляется сегодняшняя), анонс (короткий текст для списка), полный текст.
- Поле «Ссылка» — не обязательно: если новость — это пост из VK, можно указать ссылку на пост.
- Новости показываются на странице «Новости» и в блоке на главной (4 последние).

### Отключения
- Для аварий и плановых отключений воды/отопления. Показываются жёлтой плашкой на главной странице.
- Заполните: что отключается, где (адреса), с какого по какое время, причину.
- **«Показывать до»** — дата, после которой объявление само исчезнет с главной.
- Галочка «Активно» — снять = скрыть, не удаляя.

### Документы (раскрытие информации)
- Название, категория (выбор из списка), год.
- **Файл**: перетащите мышкой в пунктирное поле или нажмите и выберите на диске (PDF, DOCX, XLSX, картинки, до 25 МБ). Файл сам загрузится на сайт при сохранении — ссылки вручную прописывать не нужно. Формат документа определяется автоматически.
- **Дом** — только для протоколов собраний: выберите дом из списка, чтобы протокол был привязан к конкретному дому. Для общих документов оставьте «— общий документ —».

### Дома
- Список обслуживаемых домов. Обычно меняется редко (новый дом / ушедший дом).
- **Добавление:** улица и номер выбираются из списков (реестр домов города) — опечатки исключены. Если улицы нет в списке — «➕ Другая улица».
- Дубликат создать нельзя — админка проверит и подскажет.
- **Дом ушёл в другую УК** → кнопка «В архив»: дом исчезает с сайта и карты, но остаётся в базе внизу списка. **Дом вернулся к нам** → «Вернуть из архива» — и он снова на сайте.
- Координаты и характеристики (год, этажи, площадь) у нового дома подтянет сверка с реестром (делает администратор сайта).

### Платные услуги
- Список услуг с ценами по категориям. Цена в рублях, единица (шт/услуга/выезд).
- Цена пустая = на сайте будет «по запросу».

### Вопросы и ответы
- Вопрос и развёрнутый ответ. Показываются на странице FAQ.

### Полезное (статьи)
- Статьи для жителей («Как передать показания» и т.п.). Ключ — короткое слово латиницей (часть адреса страницы).

### Заявки с сайта и Посты VK
- Только просмотр. Заявки приходят с формы сайта, посты подтягиваются из VK автоматически.

## Правила хорошего тона

- Проверяйте текст перед сохранением — он сразу уйдёт на сайт.
- Удаление подтверждается отдельной страницей. Если удалили по ошибке — скажите администратору, восстановим из истории (все версии хранятся в git).
- Одна запись = одно сохранение. Можно править много записей подряд — сайт пересоберётся один раз.
- Если что-то сломалось или не сохраняется — сообщение об ошибке показывается красным внизу экрана; скопируйте его администратору.
