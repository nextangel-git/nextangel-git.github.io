# Передача сайта УК «Жилкомсервис» (отвязка от аккаунта разработчика)

Всё бесплатно, ~30 минут. После передачи аккаунт разработчика из системы уходит полностью.

## Что передаётся

- Репозиторий (код + данные + история + Actions) — через GitHub Transfer
- Админка — через новый токен из аккаунта УК
- Домен jks.ooo — переводится на аккаунт/регистратора УК (или остаётся у владельца домена)
- Задача синхронизации mingkh — на компьютер УК или у разработчика как сервис

## Шаги

1. **Аккаунт УК в GitHub**: регистрация на почту uk@jks.ooo (например, логин `uk-zhilkomservis`).
2. **Перенос репозитория**: в репо → Settings → General → внизу Transfer ownership → на аккаунт УК. Принять на стороне УК (письмо). Pages, Actions, история переезжают сами. Старый адрес получает редирект.
3. **Токен для админки УК**: в аккаунте УК → Settings → Developer settings → Personal access tokens → Fine-grained → новый: репо сайта, Contents: Read and write. Его вводят на компьютере УК при «первичной настройке» админки, пароль придумывает сотрудник.
4. **Отозвать токен разработчика** (его PAT больше не нужен).
5. **Домен**: DNS jks.ooo → CNAME на `<аккаунт-УК>.github.io` + в репо Settings → Pages → Custom domain = jks.ooo. После этого адрес сайта вообще не зависит от аккаунта.
6. **Синк mingkh**: либо задача на компьютере УК (та же автоматизация), либо остаётся у разработчика как сервис по договорённости.

## Проверка после передачи

- [ ] Сайт открывается (по домену/новому адресу)
- [ ] Админка на компьютере УК: вход паролем + капча, правка новости → сайт обновился
- [ ] GitHub Actions в аккаунте УК зелёные
- [ ] Токен разработчика отозван
