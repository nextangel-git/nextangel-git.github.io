# Инструкция администратора сайта

Для технического администратора (не контент-редактора — ему ADMIN-GUIDE.md). Работа с пользователями, синхронизация, бэкапы, типовые проблемы.

## Архитектура в двух словах

Сайт — статика (Astro), данные — JSON в git-репозитории. Админка — страница `/admin` на самом сайте: сохранение = коммит в репозиторий через GitHub API → GitHub Actions пересобирает сайт за 2–3 минуты. Серверов нет.

## Доступы

- **Админка сайта** (`/admin`): вход пароль + «Я не робот». Привязка к браузеру делается один раз («Первичная настройка»: токен GitHub + придуманный пароль). Смена пароля — внутри админки. Сброс привязки — ссылка на экране входа.
- **Токен GitHub (PAT)**: создаётся в аккаунте владельца репо: Settings → Developer settings → Fine-grained tokens → только репо сайта, Contents: Read and write. Хранится у администратора; в коде сайта его нет.
- **Репозиторий**: github.com → аккаунт УК (после передачи — см. HANDOVER.md).

## Пользователи админки

У каждого сотрудника — свой браузер со своей привязкой (пароль он придумывает сам). Несколько людей могут работать с одним токеном, но лучше — свой fine-grained PAT на человека: отзывается точечно.

## Синхронизация данных

- **Дома (ГИС ЖКХ)** — автоматически 5-го числа каждого месяца. Ничего делать не нужно. Вручную: локальная админка (`ЗАПУСК-АДМИНКИ.bat` → «Синхронизация») — там же кнопка постов VK.
- Защита: если реестр собрался криво (<100 домов), синк молча ничего не меняет.

## Бэкапы

- Код и данные — вся история в git (GitHub). Откат любого изменения: история коммитов → revert.
- Локально: скачанные файлы документов (при переезде на хостинг уезжают туда же).

## Типовые проблемы

| Симптом | Причина | Решение |
|---|---|---|
| «Токен отклонён» | PAT отозван/протух | Новый PAT → «Сбросить привязку» на экране входа → настроить заново |
| Правка не видна на сайте | Сборка идёт 2–3 мин | Проверить Actions в репо (зелёная галочка) |
| Сайт не открывается | — | Проверить github.com/status; затем Actions |
| Капча не рисуется | Блокировщик рекламы | Разрешить smartcaptcha.yandexcloud.net |
| Сломали данные | Ошибочная правка | git revert коммита из админки — сайт вернётся |

## Контакты

Разработка и сопровождение: Денис. Срочное по сайту: сначала проверить Actions и github.com/status.
