# Проект «ЖКС» — новый сайт ООО УК «Жилкомсервис» (Сосновоборск)

## Что это

Полное пересоздание сайта управляющей компании jks.ooo (1С-Битрикс 2015 года, cp1251, неадаптивный)
в современный быстрый статический сайт с headless CMS.

## Архитектура

```
jks.ooo/
├── AGENTS.md        # конвенции проекта (SUMMARY всегда актуален и т.д.)
├── SUMMARY.md       # обзор проекта (обновляется при каждом изменении!)
├── PRESENTATION.md  # сценарий показа сайта УК + вопросы к ним
├── jks-site/        # Сайт: Astro 7, статика, 51 страница
│   ├── src/pages/   # 8 основных + /news/[id] + /useful/[slug]
│   ├── src/layouts/ # Base.astro — шапка/подвал/VI-режим в одном месте
│   ├── src/lib/     # content.js — слой данных: Strapi → фолбэк на JSON
│   ├── src/data/    # houses.json, documents.json, news.json, services.json, …
│   └── public/      # logo.svg (оригинальный вектор), robots.txt, documents/
├── jks-cms/         # Strapi 5 + SQLite — админка для сотрудников УК
│   ├── src/api/     # типы: house, document, news-item, service-category
│   └── src/seed/    # сид-данные (заливаются при первом запуске)
├── migration/       # скрипты переноса контента + слепки старого сайта + redirects-map.md
└── references/      # скриншоты референсов (топ-УК России) и прототипа
```

- **⚠️ О свежести данных (07.11.2026):** ГИС ЖКХ через агрегаторы (mkdbase и др.) показывает устаревшие списки — считает Жилкомсервису 117 домов, включая давно ушедшие. Вывод: источник истины по домам — только сама УК. Сайт УК тоже отставал (не были убраны прекращённые). Список домов теперь правится через CMS — УК может поправить его за минуту
- **Полный реестр МКД города (08.11.2026, dom.mingkh.ru = зеркало ГИС ЖКХ):** всего 147 домов. Карта покрывает 145 (104 ЖКС + 41 конкуренты); Лен.Ком. 3 и Юности 5 сняты по уведомлениям УК. Организации: Жилкомсервис 104, Жилкомцентр 21, Мироградъ 7, Сосновоборская 4, Восходящая 1, ТСЖ/ТСН по 1 (Изумруд, Вербена, Новосел, Соседи, Мироградъ, Наша крепость, Весенняя-4), Юности 43 — без УК. **Нашлось всё, включая «ничейные» дома**

## Стек и решения

- Astro (статика) — быстро, дёшево хостится, нечему ломаться
- Strapi + SQLite — база и API под капотом (админка Strapi только английская — v5 выкинул переводы)
- **Мини-админка на русском** (`jks-site/scripts/rebuild-server.mjs`, порт 4777, `/admin`): 3 формы — новость, отключение, документ. Сотрудник УК не видит Strapi вообще. Пароль в `.env` (ADMIN_PASSWORD), запись в Strapi по токену, автопересборка после публикации
- **Версия для слабовидящих** — панель настроек: 3 размера шрифта (A/A+/A++), отключение изображений, увеличенные интервалы (ГОСТ Р 52872)
- **FAQ** (/faq) — 9 частых вопросов жителей, аккордеон
- **Антиспам на форме**: ханипот + time-trap (ботам — фальшивый «успех»)
- Favicon из логотипа, schema.org Organization (JSON-LD)
- SEO: OG-теги, canonical, sitemap.xml, robots.txt, 404
- better-sqlite3 зафиксирован на ^13.0.3 (под Node 24; v12 не собирается без MSVC)
- Strapi ограничивает pageSize=100 — слой данных листает страницы сам (баг найден и исправлен 08.11: из CMS подтягивались только 100 домов)
