- **Целевой хостинг: простой статический** (решение Дениса 17.11.2026 — VPS не нужен, админка работает через GitHub API из браузера). Провайдера Денис выберет позже; подойдёт любой статический/shared (Beget ~170 ₽/мес и т.п.).
