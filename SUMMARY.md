# Проект «ЖКС» — новый сайт ООО УК «Жилкомсервис» (Сосновоборск)

## Что это

Полное пересоздание сайта управляющей компании jks.ooo (1С-Битрикс 2015 года, cp1251, неадаптивный)
в современный быстрый статический сайт с админкой на русском — без внешних CMS и серверов.

## Архитектура (с 09.11.2026 — финальная)

Всё внутри GitHub. Strapi удалён полностью — данные живут в JSON-файлах прямо в репозитории.

```
Сотрудник УК → https://nextangel-git.github.io/admin → GitHub API (коммит в src/data/*.json)
                                                          ↓ push
                                                   GitHub Actions: npm ci → astro build
                                                          ↓
                                                   GitHub Pages (сайт)
```

```
jks.ooo/
├── AGENTS.md        # конвенции проекта (SUMMARY всегда актуален и т.д.)
├── SUMMARY.md       # этот файл (обновляется при каждом изменении!)
├── DEPLOY.md        # инструкция по развёртыванию
├── PRESENTATION.md  # сценарий показа сайта УК + вопросы к ним
├── jks-site/        # git-клон репозитория = весь сайт целиком
│   ├── src/pages/   # страницы + admin.astro (админка)
│   ├── src/layouts/ # Base.astro — шапка/подвал/VI-режим в одном месте
│   ├── src/lib/     # content.js (читает JSON), github-admin.js, collections.mjs
│   ├── src/data/    # источник истины: houses.json, documents.json, news.json, …
│   └── public/      # logo.svg (оригинальный вектор), robots.txt, documents/
├── migration/       # скрипты переноса + mingkh_sync.py + слепки старого сайта
└── references/      # скриншоты референсов (топ-УК России) и прототипа
```

- **Прод-сайт:** https://nextangel-git.github.io (GitHub Pages, автосборка при push)

## Стек и решения

- **Astro 7 (статика)** — быстро, дёшево хостится, нечему ломаться
- **Данные = JSON в репо** (`src/data/*.json`), читаются при сборке. Никаких БД и CMS-серверов
- **Собственная админка** — классическая серверная (`admin/`, Express, по-русски): логин/пароль (bcrypt) + **TOTP 2FA** (Google Authenticator / Яндекс Ключ) + **капча**, сессии 8 ч, защита от перебора. Сохранение = запись JSON → git push → Actions пересобирают сайт за 2–3 минуты; PAT живёт только на сервере. Запуск локально: `ЗАПУСК-АДМИНКИ.bat` → http://127.0.0.1:4777. Статичная `/admin` на Pages (вход токеном) оставлена как резерв. Баг 09.11: дашборд падал из-за отсутствующего requests.json — исправлено
- **Версия для слабовидящих** — панель настроек: 3 размера шрифта, отключение изображений, интервалы (ГОСТ Р 52872)
- **FAQ** (/faq) — 9 частых вопросов жителей, аккордеон
- **Антиспам на форме**: ханипот + time-trap (ботам — фальшивый «успех»)
- Favicon из логотипа, schema.org Organization (JSON-LD)
- SEO: OG-теги, canonical, sitemap.xml, robots.txt, 404
- Мобильная версия проверена на 390px
