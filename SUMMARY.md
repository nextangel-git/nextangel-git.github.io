```
Сотрудник УК → https://nextangel-git.github.io/admin → GitHub API (коммит в src/data/*.json)
                                                          ↓ push
                                                   GitHub Actions: npm ci → astro build
                                                          ↓
                                                   GitHub Pages (сайт)
```

```
jks.ooo/
├── AGENTS.md        # конвенции проекта (SUMMARY всегда актуален и т.д.)
```

## Стек и решения

- **Astro 7 (статика)** — быстро, дёшево хостится, нечему ломаться
- **Данные = JSON в репо** (`src/data/*.json`), читаются при сборке. Никаких БД и CMS-серверов
- **Серверная админка** (`admin/`, Express, локальная): логин/пароль (bcrypt) + капча, сессии 8 ч, защита от перебора. 2FA отключена (17.11.2026). Сохранение = запись JSON → git. Два режима (env): локально/GitHub Pages — push → Actions пересобирают сайт за 2–3 минуты; на VPS (REBUILD=1) — сайт пересобирается прямо на сервере за 1–2 минуты, GitHub = бэкап. Запуск локально: `ЗАПУСК-АДМИНКИ.bat` → http://127.0.0.1:4777. Статичная `/admin` на Pages — резерв. Баг 09.11: дашборд падал из-за отсутствующего requests.json — исправлено
- **Целевой хостинг: простой статический** (решение Дениса 17.11.2026 — VPS не нужен, админка работает через GitHub API из браузера). Провайдера Денис выберет позже; подойдёт любой статический/shared (Beget ~170 ₽/мес и т.п.). Файлы документов (148 МБ) зальются на хостинг при переезде (шаг 3.1 DEPLOY-VPS.md применим и к shared, только без Node). `DEPLOY-VPS.md` + `deploy/` (nginx/pm2) остаются как опция, если передумаем.
- **Версия для слабовидящих** — панель настроек: 3 размера шрифта, отключение изображений, интервалы (ГОСТ Р 52872)
- **FAQ** (/faq) — 9 частых вопросов жителей, аккордеон
- **Антиспам на форме**: ханипот + time-trap (ботам — фальшивый «успех»)
- Favicon из логотипа, schema.org Organization (JSON-LD)
- SEO: OG-теги, canonical, sitemap.xml, robots.txt, 404
- Мобильная версия проверена на 390px
