## Данные и обновление

Реестр обслуживаемых домов подтверждает УК. Технические характеристики и сведения о других организациях получены из открытого реестра mingkh/ГИС ЖКХ; эти данные могут отставать от фактического состояния. Сверку выполняет отдельный скрипт, а не сам браузер посетителя.

Посты VK подготавливаются отдельным скриптом. Новости, документы, статьи, FAQ, отключения и услуги редактируются в админке. Сохранение запускает сборку GitHub Pages; публикация подтверждается успешным результатом Actions.

При проверке 19.11.2026: 104 дома, 41 запись других организаций на карте, 9 FAQ, 4 поста VK и одна полезная статья. Новости и документы пока пусты. Тарифные документы 2018–2019 на текущую страницу не перенесены. Источник подробного состояния — SUMMARY.md.

## Возможности и ограничения

Есть мобильная версия, настройки для слабовидящих, поиск домов, карта, архив домов и фильтры документов. Наличие этих функций не является сертификатом соответствия стандартам доступности.

Заявка отправляется через FormSubmit на uk@jks.ooo. УК должна активировать адрес и подтвердить получение контрольного обращения. При ошибке предлагается письмо через почтовый клиент или обращение по телефону. Номер обращения создаётся на сайте; отслеживания его статуса в личном кабинете и журнала заявок в админке нет.

На новом статическом хостинге нужно настроить доставку сборки: сохранение через GitHub API автоматически обновляет текущий GitHub Pages, а не любой выбранный сервер.

## Что нужно от УК до приёмки

1. Подтвердить актуальный перечень домов и контакты.
2. Передать действующий прайс, тарифы и документы для открытого размещения.
3. Подтвердить банковские реквизиты и сведения о лицензии, если они должны быть опубликованы.
4. Согласовать текст политики обработки данных и используемый сервис доставки обращений.
5. Активировать FormSubmit и подтвердить доставку на почту УК.
6. Согласовать домен, ответственного за публикацию и дальнейшую синхронизацию данных.
