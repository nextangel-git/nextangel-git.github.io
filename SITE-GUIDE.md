# Сайт УК «Жилкомсервис» — описание для владельца

Основной адрес — https://jks.ooo на NIC.RU; https://nextangel-git.github.io остаётся зеркалом публичных страниц. Публичный сайт статический, новая админка `/admin` использует серверный PHP API и вход по логину/паролю. Приватная конфигурация размещена, вход и чтение данных через API проверены. Новый интерфейс опубликован и проверен в живом браузере: вход, девять коллекций, выход и мобильная ширина 390px, включая версию для слабовидящих. Реальное сохранение в рабочий репозиторий ещё не проверялось; состояние выпуска — в SUMMARY.md. Технические инструкции — DEPLOY.md, работа сотрудника — ADMIN-GUIDE.md.

## Данные и обновление

Реестр обслуживаемых домов подтверждает УК. Технические характеристики и сведения о других организациях получены из открытого реестра mingkh/ГИС ЖКХ; эти данные могут отставать от фактического состояния. Сверку выполняет отдельный скрипт, а не сам браузер посетителя.

Для постов VK подготовлен серверный сбор официального публичного виджета без входа в VK и без пользовательского браузера: сохраняются последние 10 записей, на главной показываются четыре. В админке посты доступны только для просмотра. Полная календарная дата отображается как YYYY-MM-DD; если источник сообщает только «вчера» или дату без года, дата карточки остаётся пустой.

Обновление VK и реестра домов готовится к переносу в cron NIC.RU. Чтение VK с хостинга проверено; включение расписания и публикация новых данных — отдельный шаг, статус указан в SUMMARY.md. После передачи задач серверу старые локальные запуски блокируются, чтобы они не конкурировали за одни данные. При ошибке или неполном ответе источника сохраняется предыдущая версия данных.

Новости, документы, статьи, FAQ, отключения и услуги редактируются в админке. После настройки входа сохранение создаёт коммит через серверный GitHub API. Actions собирает сайт и доставляет его на NIC.RU и зеркало Pages; публикация подтверждается успешной job deploy-nic и проверкой сайта. Сотруднику не нужен токен GitHub в браузере.

При проверке 19.11.2026: 104 дома, 41 запись других организаций на карте, 9 FAQ, 4 поста VK и одна полезная статья. Новости и документы пока пусты. Тарифные документы 2018–2019 на текущую страницу не перенесены. Источник подробного состояния — SUMMARY.md.

## Возможности и ограничения

Есть мобильная версия, настройки для слабовидящих, поиск домов, карта, архив домов и фильтры документов. Наличие этих функций не является сертификатом соответствия стандартам доступности.

Для заявки обязательны квартира и Yandex SmartCaptcha. Данные сначала принимает сервер NIC.RU, проверяет капчу и затем отправляет через FormSubmit на uk@jks.ooo. Капча также включена на входе администратора; серверный секрет установлен, выпуск опубликован 19.11.2026. УК должна активировать адрес и подтвердить получение контрольного обращения. При ошибке предлагается письмо через почтовый клиент или обращение по телефону. Номер обращения создаётся на сайте; отслеживания его статуса в личном кабинете и журнала заявок в админке нет.

Доставка на NIC.RU уже включена: FTPS-секреты настроены, `NIC_DEPLOY_ENABLED=true`, успешный выпуск подтверждён Actions. При смене хостинга отдельно перенастраиваются доставка сборки и серверная PHP-админка с её приватной конфигурацией.

## Что нужно от УК до приёмки

1. Подтвердить актуальный перечень домов и контакты.
2. Передать действующий прайс, тарифы и документы для открытого размещения.
3. Подтвердить банковские реквизиты и сведения о лицензии, если они должны быть опубликованы.
4. Согласовать текст политики обработки данных и используемый сервис доставки обращений.
5. Активировать FormSubmit и подтвердить доставку на почту УК.
6. Подтвердить ответственного за публикацию на jks.ooo, доступы админки и дальнейшую синхронизацию данных.
